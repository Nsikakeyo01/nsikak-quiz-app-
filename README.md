# Nsikak Quiz App

## Project Description
This is a JavaScript Quiz Application built for CSE 310 Module #3. It demonstrates DOM manipulation, ES6 array methods, recursion, and use of external libraries.

---

## Features
- Interactive quiz system
- Score tracking
- Multiple-choice questions
- Final result display
- Restart quiz option
- ES6 array methods used
- Recursion implemented
- SweetAlert2 alerts

---

## Technologies Used
- HTML
- CSS
- JavaScript (ES6)
- SweetAlert2

---

## How to Run
1. Open project folder
2. Open index.html in browser
3. Start quiz
